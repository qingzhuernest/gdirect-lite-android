# Android 设备与网络验收

为每次测试记录平台、版本、构建提交、设备、系统、连接模式和结果。测试用账号及文件应与日常数据分开。真实设备、账号和运营商结果分别记录。

## Android

- **安装与授权**。验证固定签名预览能覆盖同身份的旧版。测试首次只读授权、重启恢复、离线启动后联网、SDK 临时网络错误/超时后有界恢复、拒绝升级管理权限、主动断开和撤销。断开后，旧请求不能发往新账号。
- **浏览与返回**。测试首页与文件、搜索、分页、排序、共享云盘、快捷方式及文档导出。重启后不进入连接页，确认恢复授权后自动加载；断网再联网、切换 Wi-Fi/移动网络应自动重连。临时失败最多延迟重试一次，分页失败保留已显示文件。检测完成返回时应自动衔接失败目录。目录加载后静置，确认请求不会循环。测试加载中返回、清空未提交搜索、深层目录返回和旋转后重建。
- **管理与共享**。在专用测试目录创建、上传、重命名、星标、移动、移入回收站和恢复。检查回收站菜单、写操作确认、文件版本冲突和过期菜单。对专用测试账号验证权限变更；复制链接不应改变权限。
- **传输与预览**。测试大小和可用 MD5、中断续传、停止、磁盘不足、同名上传和安全重试。验证通知和浏览器入口直接打开传输页。PDF、图片、文本和媒体分别用实际设备及文件提供器检查。
- **连接与日志**。验证系统网络、仅 Google、明确同意的第三方中转；覆盖官方范围取得、备用地址、缓存清除、切换 Wi-Fi/移动网络、取消和中转失败回退。覆盖纯 IPv4、双栈、IPv6 无响应、IPv4 无响应及 IPv6 默认路由消失；高级 IP 输入检查 IPv6 完整长度。分别核对账号、API 可达和传输结果。导出日志前检查脱敏。
- **界面与无障碍**。覆盖日夜主题、360dp 宽度、横屏、放大字体、键盘、系统返回、TalkBack、通知拒绝和启动器图标。

Android RouteShelf 1.0.2-preview（versionCode 24）已有两种构建各 255 项 JVM 测试、11 项独立检查、真实 IPv4/IPv6 回环 TLS、编译与 Lint 记录。IPv6 覆盖三种 TLS 身份、错证书拒绝、双向黑洞隔离、AAAA、范围排除和日志脱敏。另覆盖手动重验与列表同时进行、缓存重验/回退、取消和存储失败保留健康路线。维护者的 0.8.5 日志记录实际 IPv4 授权/目录和检测，见 [反馈分析](history/CONNECTION_REPORT_0_8_5.md)。维护者提供了 RouteShelf 目录截图，并反馈需要手动检测才能恢复。新增自动恢复的 15 项测试覆盖会话/网络变化、一次延迟重试、检查完成衔接和防循环；另有 9 项账户恢复测试覆盖离线、SDK 7/15、次数限制、换网及旧回调隔离，包含合入的批量下载回归；1.0.2 真机自动重连、真实账号传输和运营商 IPv6 结果仍待补齐。
